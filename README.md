## Sobre mí

Ingeniero de software enfocado en **autonomía verificada**: agentes que ejecutan
trabajo real —shell, código, escritorio— con trazabilidad, verificación y
presupuesto, en lugar de promesas sin comprobar.

- 🔭 Construyendo **OpenCarls**, un daemon agéntico perpetuo en Bun + TypeScript.
- 🧰 Diseñando **servidores MCP** para edición, computer use, visión y despliegue.
- 🎮 Experimentando con **juegos web** y simulaciones en TypeScript.
- 🧪 Obsesionado con los tests, los límites claros y los entornos aislados.

## Cómo trabajo

```text
1. Entender el problema antes de escribir código.
2. Verificar cada afirmación con una prueba, no con una corazonada.
3. Aislar el entorno; dar autonomía real dentro de límites explícitos.
4. Medir, registrar y dejar rastro de lo que el sistema hizo.
```
